1  Overview & Research Questions

This practicum explores the New Complete Belgrade Beatles dataset — a comprehensive CSV that merges all Spotify audio features with the Belgrade Billboard/genre data and additional tags (Themes, Moods, Styles) as well as multiple chart and popularity measures. We apply three key Pandas techniques:

  • Filters – selecting subsets of rows based on boolean conditions
  • Bins – converting continuous values into labelled categorical tiers
  • GroupBy – applying aggregate functions simultaneously to distinct subsets

Throughout we observe how tidy data is a prerequisite for each technique, especially the need to split() and explode() multi-value string columns before grouping.

5  GroupBy

5.1  Preparing Genre Data – Explode then Group

A key challenge: the Genre column stores multiple genres as a single comma-separated string (e.g. "Blues Rock, Pop/Rock"). If we groupby('Genre') on un-exploded data, the song gets placed into a unique combined group rather than into each individual genre. The fix is always to split and explode first.

df_genres = df.copy()

df_genres['Genre'] = (
    df_genres['Genre']
    .str.lower().str.strip()
    .str.split(',')
)

df_genres_exploded = df_genres.explode('Genre').copy()
df_genres_exploded['Genre'] = df_genres_exploded['Genre'].str.strip()

genre_map = {
    'pop/rock': 'pop rock', 'r&b': 'rhythm and blues',
    'rock and roll': 'rock', 'rock & roll': 'rock',
    'experimental music': 'experimental',
}
df_genres_exploded['Genre'] = df_genres_exploded['Genre'].replace(genre_map)

print(f'Rows after explode: {len(df_genres_exploded)}')
Rows after explode: 782

Exploding expands the original 310 rows to 782 rows — confirming that many songs carry multiple genre labels. Now each row has exactly one genre and is ready for groupby.

Methodological Reflection

What Worked

  • Tidy data is non-negotiable. Every groupby on a multi-value column (Genre, Moods, Themes) required a split() + explode() step first. Skipping this step produces meaningless groups — a song tagged "Blues Rock, Pop/Rock" would become its own unique group rather than being counted in both blues rock and pop rock.
  • cut vs. qcut: cut (equal-width) is best for domain-grounded categories such as musical tempo markings, where the bin edges have genuine music-theoretical meaning. qcut (equal-count) is better for purely statistical comparisons where we want evenly-sized groups for fair rank comparisons.
  • Filtering before grouping focuses the analysis and reduces noise — the era-popularity analysis would have been muddied if we included every track regardless of streaming performance.
  • Normalising heatmap values within each column was essential for visual comparison across features with very different scales and distributions.

Challenges Encountered

  • Missing values in numeric columns caused silent errors until we explicitly cast with pd.to_numeric(..., errors='coerce').
  • The Songwriter(s) column contains many variants of joint authorship (e.g. "Lennon, McCartney", "McCartney, with Lennon"). Splitting on the first delimiter gave a workable "primary songwriter" proxy, but a fully rigorous analysis would require a more careful manual coding of joint vs. single authorship.
  • Album name inconsistencies (e.g. "UK: Help! US: Beatles VI" vs. just "Help!") meant the heatmap included some compilation/re-release titles. Restricting to albums with ≥5 tracks reduced most noise.

Musical Conclusions

The data consistently support a narrative of progressive stylistic expansion: from energetic, valence-positive early pop-rock toward increasingly diverse genre, mood, and sonic profiles in the psychedelic and late periods. That the late period nevertheless produces the most high-streaming-popularity tracks suggests the band's formal innovations — Abbey Road's medley structure, Harrison's lyrical guitar writing, the studio craft of Revolver — have deepened rather than diminished their audience over time. The Spotify popularity data (capturing current listening behaviour) thus acts as a live cultural referendum that largely, but not perfectly, agrees with traditional critical consensus.
